Nama : App Perpustakaan(Latihan RESTful API)

Tools : Laravel, Postman

Deskripsi

Aplikasi Peminjaman Perpustakaan merupakan aplikasi yang saya buat untuk berlatih membuat RESTful API berdasarkan logika bisnis dan Eloquent Relationship RDBMS. Selain itu dengan aplikasi ini saya bisa berlatih melakukan testing endpoint dengan bantuan Postman. Apa yang sajikan aplikasi ini masih berupa back-code yang masih terus dikembangkan.

Controller

  • BukuController : function index, create, show($id), updated, patchUpdate, destroy(id)
  • PeminjamanController : function index, create, show($id), kembali($id), kembalikan($id)
  • AuthController : function login, register

Route

Route ini dibuat di file api.php, yang merupakan hasil instalasi api route bawaan laravel dengan perintahi "php artisan install:api". Lalu di dalamnya sudah ada beberapa endpoint yang saya buat dengan masing-masing method sesuai keperluan.

POSTMAN API Testing

Setelah membuat Route, saya melakukan test endpoint menggunakan POSTMAN untuk memastikan apakah mmethod GET, POST, PUT, PATCH, DELETE sudah berjalan sesuai kebutuhan.
